# Python Stock Portfolio Tracker

## About
A command-line Python application for tracking stock holdings
and calculating portfolio values.

## Features
- Add stocks to a portfolio
- Calculate investment values
- Calculate portfolio weights
- Display portfolio information
- Save portfolio data to CSV or TXT files

## Technologies Used
- Python
- CSV module
- Datetime module
- File handling
- Dictionaries and lists

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Run:

   python stock_portfolio_tracker.py
